# STM32 多功能智能电子锁

基于 STM32F103C8T6 主控 + FreeRTOS 操作系统的多功能智能电子锁实训项目，支持 RFID 刷卡、指纹识别、人脸识别、4×4 按键四种解锁方式，OLED 中文显示。

## 📋 功能特性

- 🔑 **四种解锁方式**：RFID 刷卡、指纹识别、人脸识别、按键密码
- 📺 **OLED 中文显示**：支持汉字反显，界面清晰，无文字重叠
- ⏱️ **多任务并行**：基于 FreeRTOS 实时操作系统，各模块独立运行不阻塞
- 🛡️ **防误触设计**：操作过程屏蔽功能按键，* 键全局一键退出
- ⚡ **刷卡防抖**：1 秒内重复刷卡不重复触发，避免反复开关锁
- ⏰ **超时保护**：RFID 刷卡界面 5 秒无卡自动返回主页
- 🔒 **统一开锁逻辑**：所有解锁方式共用 2 秒自动落锁机制

## 🏗️ 软件架构

基于 **FreeRTOS 实时操作系统 + 状态机** 架构，CMSIS-RTOS 接口，静态内存分配。

### 任务分配

| 任务 | 优先级 | 栈大小 | 功能 |
|------|--------|--------|------|
| 按键扫描任务 | 高 | 256 Word | 4×4 按键扫描，模式切换 |
| 人脸识别任务 | 中 | 512 Word | 人脸录入、验证、删除 |
| RFID 读卡任务 | 中 | 512 Word | MFRC522 寻卡、校验、开锁 |
| 指纹识别任务 | 中 | 512 Word | 指纹录入、比对、清空 |
| OLED 刷新任务 | 低 | 256 Word | 界面显示与状态提示 |

### 工作状态
APP_STATE_IDLE // 空闲：后台持续指纹比对
APP_STATE_FACE_ENROLL // 人脸录入
APP_STATE_FACE_DELETE // 删除全部人脸
APP_STATE_FACE_VERIFY // 人脸验证开锁
APP_STATE_FP_ENROLL // 指纹录入
APP_STATE_FP_DELETE // 删除全部指纹
APP_STATE_RFID_READ // RFID 刷卡
APP_STATE_UNLOCK_DELAY // 开锁延时（2 秒自动落锁）


### 按键映射

| 按键 | 功能 |
|------|------|
| `1` | 人脸录入 |
| `2` | 删除全部人脸 |
| `A` | 指纹录入 |
| `B` | RFID 刷卡模式 |
| `C` | 人脸验证 |
| `D` | 删除全部指纹 |
| `*` | 全局退出 / 返回主页 |


## 🚀 使用说明

### 1. 编译环境
- Keil uVision5
- STM32CubeMX（用于生成初始化代码与 FreeRTOS 配置）
- ST-Link 下载器

### 2. FreeRTOS 配置
- 接口版本：CMSIS_V1
- 调度方式：抢占式调度
- 系统节拍：1000 Hz (1ms)
- 最大优先级：7 级
- 内存分配：静态内存 + 动态堆 12KB
- 互斥锁：已开启（OLED 屏幕资源保护）

### 3. 快速上手
1. 使用 STM32CubeMX 配置外设与 FreeRTOS
2. 将各模块驱动文件加入工程
3. 在 `freertos.c` 中创建任务并实现状态机
4. 编译下载到 STM32F103C8T6
5. 上电默认进入空闲模式，可直接刷指纹开锁
